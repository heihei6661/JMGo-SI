# Core stubs

These are **type stubs only**. They document the contract that `jmgo_core`
implements; they contain no logic.

Install the real core from the private wheel index, then copy (or install) these
stubs for IDE/type-checker support:

```bash
pip install jmgo_core-<platform>.whl
```

Never commit `jmgo_core` binaries or keys to this repository.
